# TrueMax — Product Requirements Document

**Status:** implementation source of truth · **Reviewed:** 19 July 2026

## Product promise

TrueMax is a private, adult-only iPhone app for repeatable cosmetic facial
measurements and practical grooming/presentation guidance. It helps a person
understand what may work for them without attractiveness scores, public
rankings, medical claims, or uploaded face photos.

The supplied 23 design-reference images are the visual source of truth. The
implementation uses the existing Sakinah Xcode target and release identity so
the live app can be replaced without changing its App Store or RevenueCat
contracts.

## Non-negotiable boundaries

- No authentication, profile, CloudKit/iCloud sync, ads, analytics, or remote
  face/model service.
- Capture JPEGs, Vision landmarks, transient depth summaries, derived ranges,
  favorites, and history remain in protected local storage.
- Raw depth maps are never persisted. RevenueCat receives purchase and
  entitlement data only; no face, age, scan, or coaching attributes.
- Guidance is cosmetic and informational. It must not diagnose, rank people,
  infer sensitive traits, prescribe treatment, or create an idealized face.
- Adult gate: iOS 26+ uses the privacy-preserving declared-age-range signal;
  older/unavailable systems use explicit 18+ self-attestation. No birth date is
  requested or stored.

## Core workflows

1. Welcome → capability explanation → 18+ age gate → privacy explainer.
2. Custom paywall with annual selected by default and monthly selectable.
3. Paywall CTA is stateful: “Checking plan…”, “Start Free Trial” only when the
   selected StoreKit product has an eligible three-day introductory offer, or
   “Continue Pro — Annual/Monthly” when no offer applies. Unknown eligibility
   stays blocked with a retry action rather than claiming a trial.
4. Home → checklist → TrueDepth camera when available, otherwise clearly
   labeled Photo mode → on-device Vision analysis → result reveal → local save.
5. Results show estimate bands for symmetry, proportion, canthal tilt, jaw
   contour, and visible skin texture, each with methodology and guardrails.
6. History supports private comparison, individual deletion, and Delete All;
   Settings supports restore purchases, appearance theme switching (dark
   default), legal links, and local data deletion.

## Measurement contract

| Metric | Computation | User-facing boundary |
|---|---|---|
| Symmetry | Reflected eye, nose, mouth, and contour landmark offsets | Alignment index, not attractiveness |
| Proportion | Eye line, nose, mouth, chin, and face-bound relationships | Balance in this capture, not an ideal ratio |
| Canthal tilt | Visible eye-line angles corrected for roll | Image estimate; not an ophthalmic measure |
| Jaw angle | Visible lower-face contour sampling | Not a clinical gonial-angle measurement |
| Visible texture | Local image contrast inside detected face bounds | Not a skin-health assessment |

Every result is a range. Band width is widened for small faces, pose, image
quality, and 2D fallback; compatible TrueDepth geometry can narrow only the
measurements it can support. “Depth-assisted estimate” is the strongest claim
the UI may make.

## Local intelligence

`TrueMaxIntelligenceLayer.swift` is a versioned knowledge base plus a
deterministic rule engine. It maps reviewed Vision/AVFoundation capture
documentation, age/privacy requirements, App Store safety boundaries, and AI
traceability practices. It uses only derived ranges and capture mode to produce
explainable action-plan signals. Each signal carries a reviewed source
identifier and safety boundary. The knowledge revision is bundled, auditable,
and updated through a normal app release; runtime web retrieval is deliberately
not used because it would conflict with the face-data privacy promise.

## Subscription contract

RevenueCat remains wired to the existing anonymous customer flow.

| Contract | Value |
|---|---|
| Entitlement | `Sakinah Premium` (fallback `premium`) |
| Monthly | `com.socialreporthq.sakinah.premium.monthly` |
| Annual | `com.socialreporthq.sakinah.premium.annual` |
| Legacy restore-only product | `com.socialreporthq.sakinah.premium.lifetimev2` |
| Introductory offer | Three days, only when StoreKit says eligible |

The lifetime product is recognized during restoration but is not sold. Prices
and trial availability are always read from StoreKit/RevenueCat; copy never
hard-codes a price or claims an unavailable offer.

## Accessibility and safety acceptance

- Dynamic Type is supported with semantic SwiftUI fonts and single-column
  layouts at accessibility sizes.
- VoiceOver labels describe ranges, capture mode, privacy state, comparison
  ordering, and destructive deletion actions.
- Dark mode is default; Light and System themes use adaptive semantic colors
  with readable action-button contrast.
- Reduce Motion, camera permission denial, unavailable TrueDepth, failed saves,
  and partial file cleanup have explicit, recoverable states.

## Release verification

The Linux contract gates are `python3 scripts/verify_truemax_contracts.py` and
`python3 scripts/verify_truemax_intelligence.py`.
Release also requires macOS/Xcode Debug and Release builds, unit/UI tests,
physical TrueDepth and 2D-device capture, StoreKit/RevenueCat sandbox tests for
both products and the three-day offer, VoiceOver/Dynamic Type/contrast checks,
and App Store privacy-answer review against the final archive.
